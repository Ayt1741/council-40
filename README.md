# council-40

Совет из 40 агентов (10 руководителей + 30 исполнителей) собирает информацию по протоколу заказчика.
Запуск: Actions → council-40 → Run workflow. Ключи — только в секретах репозитория (в коде их нет).

Порядок: план руководителей (этап 0) → 30 исполнителей ищут (раунд 1) → руководители разбирают найденное, проверяют цитаты дословно и придумывают новые запросы по ходу →
30 исполнителей ищут новые запросы (раунд 2) → десять руководителей голосуют → отчёт (`plan.md`, `findings.md`, `REPORT.md`, `council-result.json`).
