ЗАДАЧА (ход 60, объём 4000 запросов). ИИ-агент заказчика (Arena Agent Mode: bash, файлы, веб-поиск; диалог ≈1500+ сообщений) забывает и нарушает «законы» заказчика (108 правил). Заказчик требует: найти ГОТОВОЕ, уже проверенное людьми решение проблемы ПАМЯТИ (чтобы правила и сказанное не терялись), а не изобретать своё.
ФАКТЫ СРЕДЫ. Контекст платформой СЖИМАЕТСЯ; внешних хуков нет; системный промт менять нельзя; живут файлы рабочей папки, журнал (2100+ записей), панель действий с хеш-цепочкой, проверка ответа (10 проверок), гейт (7 проверок), Telegram-хранилище. Заказчик не программист, вставляет одно сообщение в новый диалог.
УЖЕ ИЗВЕСТНО (не ищи заново, только проверь при случае). Память Mem0 оставляет 57,5 % нарушений; «компиляция правил в проверки» (Trace, arXiv 2606.13174) снижает нарушения 100 %→37,6 %/2,0 %; правило в КОНЦЕ контекста соблюдается лучше, чем в начале (arXiv 2608.11242); Claude Code имеет PreCompact-хуки, у Arena их нет.
ОГРАНИЧЕНИЯ ОТВЕТА. Бесплатно; Python std-lib; без хуков платформы; проверка детерминированная; агент сам решает, запускать ли проверку.
ЧТО СЧИТАЕТСЯ НАХОДКОЙ. Рабочий код в issue/PR/репозитории с исходником, официальная документация, или ≥2 независимых источника об одном и том же. Обзорная статья без кода и ссылок — НЕ решение.
ТРЕБОВАНИЕ ХОДА 60: 10 руководителей по 100 запросов + 30 исполнителей по 100 своих запросов = 4000 поисков; запросы разные, точные, только про память/правила ИИ-агентов.
