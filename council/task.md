ПРОБЛЕМА. ИИ-агент заказчика (Arena Agent Mode: bash, файлы, веб-поиск; один диалог ≈1535 сообщений, 78,8 млн знаков) снова и снова забывает и не выполняет «законы» заказчика (≈108 постоянных правил) и сказанное в сообщениях. Нужно найти ГОТОВОЕ, уже проверенное людьми решение (код, приём, инструмент, исследование) проблемы ПАМЯТИ, после которого правила и сказанное не теряются или теряются заметно реже и ловятся сразу.

ФАКТЫ СРЕДЫ (не гипотезы):
1. Контекст периодически СЖИМАЕТСЯ платформой в краткую сводку; внешних хуков нет; системный промт менять нельзя; сессия может сменить модель при сбое. Живут: файлы рабочей папки, журнал (2100+ записей), панель действий с хеш-цепочкой и sha256, проверка ответа (10 детерминированных проверок), гейт (7 проверок), Telegram-хранилище.
2. Заказчик не программист; в новый диалог может вставить одно сообщение.
3. Правила: 108 пунктов, номера 1–5 и 60–65 повторяются, 55 % содержат запрет, есть противоречия.
4. Уже сделано и НЕ помогло: журнал «читать первым» (скрипт печатает «100 %», в контекст ничего не попадает), ядро-12, проверка ответа, гейт.
5. Уже известно из прошлых прогонов (не ищите заново, максимум проверьте): Mem0-память оставляет 57,5 % нарушений; Trace (arXiv 2606.13174) компилирует правила в runtime-проверки: нарушения 100 % → 37,6 % / 2,0 %; правило в конце контекста соблюдается на 99,7 % против 31,8 % (arXiv 2608.11242); Claude Code имеет PreCompact/Stop-хуки, у Arena Agent Mode их НЕТ.

ПРОТИВОРЕЧИЯ: заказчик считает, что законы лежат в файлах и читаются каждый ход, но нарушения продолжаются (чтение ≠ выполнение); заказчик хочет «никогда», а платформа не даёт принудительной проверки; больше правил ≠ лучше соблюдение.
